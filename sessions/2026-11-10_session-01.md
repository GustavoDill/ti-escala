## 2. Summary of Work Done
1. **Governance & Planning (`TASK-001`, `TASK-002`)**:
   - Created [`AGENTS.md`](../AGENTS.md), [`TASKS.md`](../TASKS.md), and [`PLAN.md`](../PLAN.md).
   - Incorporated user requirement: no local seed `escala.csv` is bundled in the repository/container; the initial `escala.csv` is uploaded manually to the Supabase Storage Bucket, and if missing on startup, the server displays an error and aborts main functionality (`503 Service Unavailable`).
2. **Backend & Supabase Integration (`TASK-003` to `TASK-008`)**:
   - [`src/server/csv.ts`](../src/server/csv.ts): Semicolon-delimited CSV parser & serializer with automatic `UTF-8` vs `Windows-1252` (`latin1`) character decoding, duplicate `ESCALA` header handling, and empty row stripping.
   - [`src/server/storage.ts`](../src/server/storage.ts): Startup download from Supabase Storage into ephemeral runtime cache (`.cache/escala.csv` + memory), `ERROR_MISSING_CSV` abort handling when the file is absent, and write-through `upsert` push to Supabase on every edit/upload.
   - [`src/server/auth.ts`](../src/server/auth.ts) & [`sql/init_auth.sql`](../sql/init_auth.sql): SHA-512 password hashing and constant-time comparison (`crypto.timingSafeEqual`) against `public.escala_auth` for `administrator` and `system` roles, plus [`scripts/hash-password.ts`](../scripts/hash-password.ts).
   - [`src/server/routes.ts`](../src/server/routes.ts) & [`src/server/index.ts`](../src/server/index.ts): Hono REST API (`/api/status`, `/api/escala`, `/api/escala/raw`, `/api/auth/verify`, `PUT /api/escala`, `PATCH /api/escala/cells`, `POST /api/escala/upload`, `POST /api/escala/sync`, `/healthz`).
3. **Frontend & Exports (`TASK-009` to `TASK-012`)**:
   - [`src/client/App.tsx`](../src/client/App.tsx): Read-Only default mode, Edit Mode toggle with SHA-512 [`AuthDialog.tsx`](../src/client/components/AuthDialog.tsx), missing-CSV abort screen, global Sector/Role/Search filters, and auto-sync inline editing.
   - [`src/client/components/CalendarView.tsx`](../src/client/components/CalendarView.tsx): Team Monthly Calendar + Day Roster Inspector + Per-Worker Individual Calendar with inline cell editing.
   - [`src/client/components/ComparisonView.tsx`](../src/client/components/ComparisonView.tsx): Multi-worker side-by-side schedule comparison and daily coverage analyzer with inline editing.
   - [`src/client/components/GridView.tsx`](../src/client/components/GridView.tsx): Sticky-column Excel-like spreadsheet with sortable headers, inline editing for both shift cells and worker metadata, row addition/deletion, and new date column creation.
   - [`src/client/exportUtils.ts`](../src/client/exportUtils.ts): Client-side export to `.pdf` (landscape printable report), `.xlsx` (color-coded Excel workbook with frozen headers), and `.csv` (semicolon-delimited Excel-compatible CSV).
4. **Containerization & Verification (`TASK-013`, `TASK-014`)**:
   - Created [`Dockerfile`](../Dockerfile), [`.dockerignore`](../.dockerignore), [`render.yaml`](../render.yaml), [`README.md`](../README.md), and [`tests/backend.test.ts`](../tests/backend.test.ts).
